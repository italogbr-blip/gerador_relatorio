================================================================================
GUIA DE INSTALAÇÃO: API PHP E BANCO DE DADOS MYSQL NA HOSPEDAGEM (HOSTINGER)
MMS Suporte Logístico • Gerador de Relatórios
================================================================================

A aplicação agora se conecta diretamente ao seu banco de dados MySQL na sua
hospedagem Hostinger através da API PHP contida nesta pasta "api/".

--------------------------------------------------------------------------------
1. ARQUIVOS CONTIDOS NA PASTA "api/"
--------------------------------------------------------------------------------

├── config_db.php           -> Credenciais diretas do MySQL (caso não use .mms_env)
├── db.php                  -> Conexão PDO segura (lê .mms_env automaticamente) e auto-criação de tabelas
├── auth.php                -> Login com bcrypt, cadastro, sessão e auditoria de usuários
├── relatorios.php          -> CRUD completo de relatórios, filtros, paginação e estatísticas
├── coord.php               -> Validação de senha do painel coordenação, bloqueio contra força bruta e logs
├── configuracoes.php       -> Controle de versão do app e avisos/popups ativos
├── config_anexos.php       -> Configuração e chaves de segurança dos anexos fotográficos
├── upload_anexo.php        -> Upload criptografado e seguro de fotos
├── ver_anexo.php           -> Gateway de entrega autorizada das fotos
└── storage_anexos/         -> Armazenamento protegido das imagens (.htaccess 403 Forbidden)

--------------------------------------------------------------------------------
2. COMO CONFIGURAR A CONEXÃO COM O BANCO MYSQL
--------------------------------------------------------------------------------

A API possui detecção inteligente em duas formas (escolha a que preferir):

OPÇÃO A (Recomendada - Mantém o padrão original):
O arquivo db.php localiza automaticamente o seu arquivo ".mms_env" que já fica
fora da pasta public_html (na raiz da sua conta Hostinger).
Se as variáveis DB_HOST, DB_NAME, DB_USER e DB_PASS já estiverem no .mms_env,
você NÃO precisa alterar absolutamente nada!

OPÇÃO B (Configuração direta):
Caso prefira, abra o arquivo "api/config_db.php" e informe as credenciais:
  define('MMS_DB_HOST', 'localhost');
  define('MMS_DB_NAME', 'seu_banco_aqui');
  define('MMS_DB_USER', 'seu_usuario_aqui');
  define('MMS_DB_PASS', 'sua_senha_aqui');

--------------------------------------------------------------------------------
3. COMO SUBIR PARA A HOSPEDAGEM HOSTINGER
--------------------------------------------------------------------------------

1. Acesse o hPanel da Hostinger -> "Gerenciador de Arquivos" (File Manager).
2. Vá até a pasta pública onde o domínio relatorios.atmai.com.br está apontado
   (geralmente "public_html/").
3. Envie a pasta "api/" inteira para dentro de "public_html/".
4. Verifique as permissões da pasta "public_html/api/storage_anexos/":
   - Deve estar com permissão 755 (ou 775) para escrita das fotos.

--------------------------------------------------------------------------------
4. TESTES DE FUNCIONAMENTO
--------------------------------------------------------------------------------

1. Teste de Conexão com o MySQL:
   Acesse no navegador:
   https://relatorios.atmai.com.br/api/configuracoes.php?action=obter_versao

   Retorno esperado (JSON):
   {"sucesso":true,"versao":"v...","obrigatoria":false,"notas":""}

2. Teste de Segurança da Pasta de Fotos:
   Acesse:
   https://relatorios.atmai.com.br/api/storage_anexos/

   Retorno esperado:
   403 Forbidden (Acesso Proibido - proteção ativa contra curiosos).
